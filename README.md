# The World — A Little World

An immersive, ever-changing pixel-art journey through beautiful places, accompanied by classical and flute instrumentals.

## The experience

- Full-screen pixel-art-inspired landscapes, with a new destination at the click of a button.
- Initial destinations include Egypt, Cappadocia in Türkiye, Rajasthan in India, China, Kyoto in Japan, and Bali.
- Gentle motion: drifting clouds, birds, water glimmers, and changing light.
- Add your own classical or flute audio files using **Add music**. Files are played locally in your browser and are not uploaded anywhere.
- Responsive layout for desktop and mobile.

## Run locally

Open `index.html` in a modern browser, or use a small local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Music

Choose audio files from your device with **Add music**. Supported formats depend on your browser (MP3, OGG, WAV, M4A, and others). The selected files remain on your device; reselect them after reloading the page.
